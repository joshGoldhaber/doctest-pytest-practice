# More doctest practice [![](https://github.com/joshGoldhaber/doctest-pytest-practice/workflows/tests/badge.svg)](https://github.com/joshGoldhaber/doctest-pytest-practice/actions?query=workflow%3Atests)

The purpose of this assignment is to help develop good coding habits.


## Instructions

1. Fork this repo
1. Update the `README.md` file so that the urls in the test cases badge point to your forked repo
1. Fix the python so that all test cases pass.

    > **NOTE:**
    > The python should be easy.
    > Take time to practice using the shell and vim effectively.

## Submission

Paste the URL to your github repo into canvas.
